Aprendendo o uso de git e github

uso de Branches e ramificações

O git é um sistema de controle de versão distribuído que permite aos desenvolvedores rastrear alterações no código-fonte ao longo do tempo. Uma das funcionalidades mais poderosas do git é o uso de branches (ramificações), que permite criar linhas de desenvolvimento independentes dentro de um repositório.

Mas qual é a diferença entre git e github?

Hospedagem Grátis no GitHub

O GitHub oferece hospedagem gratuita para projetos de código aberto, permitindo que os desenvolvedores publiquem e compartilhem seus repositórios com a comunidade.Claro que possui suas limitações, mas é uma excelente opção para projetos open source.
